# Opening the CAD files

These instructions describe the intended application workflow. The files were inspected structurally but have not been opened or regenerated in CFturbo or SolidWorks during preparation of this package.

## CFturbo project

1. Make a working copy of `CFTurbo/Proj1.cft`.
2. Start a compatible CFturbo installation and use its project-open command to select that copy.
3. The native file records version `10.4.5.27`, format version `10.4`.
4. Review the global duty point, the impeller main dimensions, the six blades, seven spans, and free-form geometry.
5. Compare the saved dimensions with the English report's design-stage table before changing values.
6. If opening in a newer version, check whether automatic calculations are enabled. CFturbo documents that older projects can change when recalculated in newer software. Keep the original file unchanged and save any migrated version under a new name.

The native file stores mass flow `34.722222... kg/s`, rotational frequency `24.166666... s^-1`, and specific energy `132.435 J/kg`. At the stored water density of `1000 kg/m³`, these correspond to `125 m³/h`, `1450 rpm`, and `13.5 m` head. Read internal units carefully rather than treating each raw field as the display unit.

## STEP export

1. In SolidWorks or another STEP-capable CAD application, choose File → Open.
2. Select `CFTurbo/Proj1.stp`; choose the STEP file type if necessary.
3. Review the imported bodies, surfaces, and curves, and use the application's import diagnostics if available.
4. Confirm dimensions and topology before using the import for meshing or manufacture.

The text export includes six `MANIFOLD_SOLID_BREP` entities, six `CLOSED_SHELL` entities, and additional open shells, surface models, and curve sets. These entity counts are a structural inventory, not proof that the import produces one connected, watertight, manufacturing-ready body.

## Native SolidWorks parts

Open `Solidworks/Part1.SLDPRT` and `Solidworks/Part2.SLDPRT` individually. Inspect their feature trees and sketches to identify their role. The files in `Solidworks/Junk/` are additional archive parts retained exactly as supplied; the folder name is original and does not establish whether the parts are useful or obsolete.

The archive does not specify the SolidWorks release used to create them. If a version-compatibility problem occurs, the STEP export offers a neutral geometry route, though it does not preserve the native feature history.

## SolidWorks macro

`CFTurbo/Proj1.swb` is readable source text generated by CFturbo 10.4.5. It contains routines for hub, shroud, blade-edge, pressure-surface, and suction-surface geometry, plus a `main` routine.

1. Start SolidWorks with a valid default part template configured.
2. Choose Tools → Macro → Run.
3. Locate `CFTurbo/Proj1.swb` and open it in a compatible release.
4. Review the generated document and geometry. Save the new part separately.

SolidWorks documentation describes support for SWB macros and notes that opening or editing an SWB can convert it to SWP. The original SWB is retained here. The macro has not been run or modified as part of this preparation.

- CFturbo automatic calculations: https://manual.cfturbo.com/en/automatic_updates.html
